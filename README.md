# The Last Beacon Keeper (حارس المنارة الأخير)

> **الإصدار الحالي (Current Version):** `v1.2.0`

لعبة مغامرة وبقاء وبناء تكتيكية بنمط لاعب واحد وبدون اتصال بالإنترنت (Offline Single-Player)، مبنية بالكامل بلغة **C++17** ومكتبة **SDL2** وفق المواصفات المذكورة في `idea.txt`.

---

## 🌟 الجديد في الإصدار v1.2.0 (Strategic Survival & Game Feel Update)
1. **نظام التلغراف الموجي (Wave Telegraphing):**
   - استعراض تكتيكي مصغر (Tactical Indicator) يظهر أثناء الغسق (Dusk) وفترات الهدوء بين الموجات.
   - يعرض رقم اليوم، الموجة الحالية والمجموع، أعداد وأنواع الأعداء القادمة (Crawlers, Eaters, Brutes, Leviathan)، مع عدّاد تنازلي دقيق حتى موعد الهجوم باللغتين العربية والإنجليزية.

2. **ترقيات المنارة والحارس الدائمة (Lighthouse Citadel Upgrades):**
   - واجهة ورشة عمل ثنائية اللوحة (Two-Panel Workshop UI) تعرض قائمة العناصر على اليسار وبطاقة فحص تفصيلية (Inspector) على اليمين.
   - 5 مسارات ترقية دائمة (مستويات 1 إلى 3) مع تكاليف ومضاعفات فعلية:
     - **قوة الشعاع (Beam Power):** زيادة ضرر الشعاع بنسبة +25% لكل مستوى.
     - **كفاءة الوقود (Beam Efficiency):** خفض معدل استهلاك الوقود بنسبة -25% لكل مستوى.
     - **صلابة المرايا (Mirror Durability):** زيادة صحة المرايا من 80 إلى 125 ثم 170 نقطة صحة.
     - **تدريع المنارة (Lighthouse Armor):** رفع صحة المنارة القصوى من 500 إلى 650 ثم 850 نقطة.
     - **حذاء السرعة (Swift Boots):** زيادة سرعة حركة الحارس وخفض فترة انتظار التفادي (Dash Cooldown).

3. **شاشة ملخص الفجر المخصصة (Dedicated Dawn Summary UI):**
   - بطاقة متكاملة تظهر عند بزوغ الفجر لعرض تقرير الأداء: اليوم المنجز، الموجات المصدودة، عدد صرعى الظل، سلامة المنارة بالنقاط والنسبة المئوية، الوقود المتبقي، المرايا السليمة، وتفصيل الغنائم والمكافآت المضافة لحقيبتك مع إعلان اليوم التالي دون تجميد اللعب.

4. **تكتيكات الأعداء والشعور باللعب (Game Feel & Tactical Identities):**
   - كواسر الظل (Brutes) تمتلك دروعاً مصفحة تقاوم الضربات اليدوية (تتلقى 12 ضرر فقط بدلاً من 30)، مما يفرض توجيه شعاع المنارة نحوها.
   - ملتهمو النور (Eaters) يستهدفون المرايا لتحطيم شبكة الانعكاس.
   - إنذارات تحذيرية ذكية مع مؤقت تبريد (Cooldown) عند انخفاض الوقود (<30% و <15%) أو تضرر المنارة (<50% و <25%) مع وميض بصري وأصوات إنذار تفاعلية.

## 🎮 عناصر وميكانيكيات اللعبة
1. **دورة البقاء والتعاقب الزمني المتقدمة (Survival Progression Loop):**
   - **النهار (Day / Exploration):** استكشاف الأرخبيل، تقطيع الأشجار، استخراج البلورات، تجميع الوقود، وصناعة المرايا والعدسات.
   - **الغسق (Dusk / Preparation):** نافذة تكتيكية (18 ثانية) مع تلغراف الموجة الأولى لتجهيز الدفاعات، صيانة المنارة، وإعادة توزيع المرايا.
   - **المد الظلي (Night / Wave Defense):** مواجهة موجات متصاعدة بتكوينات مدروسة مع إشعارات اجتياز الموجات.
   - **بزوغ الفجر (Dawn / Reward):** شروق شمس ذهبي يبخر وحوش الظل في شرارات ضوئية ناصعة، ويعرض ملخص الصمود والغنائم المكتسبة.

2. **فيزياء شعاع الضوء وانعكاس المرايا (Raycasting & Reflection):**
   - شعاع المنارة ينطلق بقوة ويحرق الأعداء.
   - إذا اصطدم الشعاع بمرايا نحاسية وُضعت في الساحة، ينعكس الشعاع وفق زاوية السقوط والانعكاس ($R = D - 2(D \cdot N)N$) لمسافات تصل إلى 4 ارتدادات!

3. **العدسات المتعددة (Lenses):**
   - **عدسة الشعاع المركز (Focused Solar):** تركيز حراري فتاك لإذابة الوحوش الضخمة.
   - **عدسة العنبر الواسعة (Amber Wide-Defense):** مخروط ناري عريض لحماية محيط الجزيرة ضد الأسراب.
   - **عدسة الصدمة فوق البنفسجية (UV Pulse):** كشف الأعداء وتوجيه صدمات تجميد ضوئية.

4. **المذابح الأثرية الثلاثة (Ancient Altars):**
   - **مذبح الشمس (الغرب):** يزيد من سرعة وقوة اللاعب.
   - **مذبح البلورات (الشمال):** يشحن وقود المنارة تلقائياً.
   - **مذبح البحر (الشرق):** يُضعف دروع الوحوش الكبيرة وزعيم الليل الرابع.
   - إشعال المذابح الثلاثة والوصول إلى اليوم الرابع يستدعي "الفجر الأول" وتحقيق النصر (Victory)!

5. **نظام الصوت التوليدي (Procedural Audio Synth):**
   - كافة المؤثرات الصوتية (ضربات الفأس، أصوات الليزر والارتداد، صراخ الوحوش واحتراقها، جرس الفجر، والموسيقى التفاعلية) مبرمجة رياضياً داخل C++ لتعمل دون الحاجة لملفات صوت خارجية.

6. **دعم ثنائي اللغة وتنسيق احترافي للغة العربية (Bilingual & Full Arabic Support):**
   - اللعبة تدعم اللغتين **العربية** و **الإنجليزية** بشكل كامل مع إمكانية التبديل من قائمة الإعدادات (زر `O`) أو فورياً بزر `L`.
   - استخدام خوارزمية **GNU FriBidi** لتنسيق النصوص العربية والاتجاه من اليمين لليسار (RTL) دون قلب الحروف الإنجليزية أو الأرقام (مثل: `[WASD]` و `100/100`).
   - دمج خط النسخ العربي الأصيل (Amiri Font) لتوصيل الحروف وتشكيلها بمظهر جمالي متناسق وخالٍ من الأحرف المتقطعة أو المعكوسة.

## 🕹️ أزرار التحكم (Controls)

| الزر / الإدخال | الوظيفة |
|---|---|
| **W, A, S, D** أو الأسهم | حركة الحارس في الجزيرة |
| **فأرة (Mouse Aim)** | توجيه المصباح اليدوي أو شعاع المنارة |
| **النقر الأيسر (Left Click)** | تقطيع الأشجار / تكسير البلورات / ضرب الوحوش / استخدام القائمة |
| **النقر الأيمن (Right Click) أو R** | تدوير أقرب مرآة بزاوية 45 درجة لتوجيه مسار الضوء |
| **F أو C** | وضع مرآة جديدة من الحقيبة في موضع المؤشر |
| **E** | التفاعل مع طاولة المنارة (ورشة الترقية) أو إشعال المذبح أو استرجاع مرآة |
| **Space** | مراوغة سريعة (Dash / Dodge Roll) مع وميض غباري |
| **H** | استخدام مرهم شفاء لاستعادة 50 نقطة صحة |
| **1, 2, 3** | التبديل بين العدسات (مركز / عريض / UV) |
| **T** | صعود برج المنارة والتحكم بالشعاع يدوياً بالفأرة |
| **O** | فتح قائمة الإعدادات (تغيير اللغة، ملء الشاشة، مستوى الصوت) |
| **F11 أو Alt+Enter** | التبديل الفوري بين وضع ملء الشاشة والنافذة (Fullscreen Toggle) |
| **L** | تبديل سريع بين اللغتين (العربية / English) بضغطة زر |
| **F12** | التقاط لقطة شاشة وحفظها فورياً بدقة كاملة (screenshot.bmp) |
| **M أو TAB** | فتح مذكرات الحارس وسجل المهام (Journal) |
| **ESC** | إيقاف مؤقت (Pause) / العودة |

## 🛠️ البناء والتشغيل (Build & Run)

### المتطلبات الأساسية:
- مترجم يدعم C++17 (`g++` أو `clang++`)
- مكتبات: `libsdl2-dev`, `libsdl2-ttf-dev`, `libsdl2-image-dev`, `libsdl2-mixer-dev`

### أوامر التشغيل السريعة:
```bash
# البناء والتشغيل مباشرة
make run

# أو البناء فقط
make

# ثم التشغيل
./beacon_keeper
```
